## Featured projects

### 🎮 [Death on the Cards — Backend](https://github.com/lautarofamaf/dotc-backend)

Backend for a real-time multiplayer adaptation of the board game *Death on the Cards*, developed as part of a Software Engineering project.

- Designed around layered architecture and separation of responsibilities.
- Real-time communication through **WebSockets**.
- Asynchronous server workflows for concurrent clients and game sessions.
- Domain-driven game logic with specialized services and effect execution.
- REST API interfaces, dependency injection, persistence, and automated tests.

**Tech:** `Python` `FastAPI` `WebSockets` `SQLAlchemy` `Pytest` `uv`

### 🐾 [DiagnoVET API](https://github.com/lautarofamaf/diagnovet-challenge)

Backend engineering challenge for processing veterinary reports in PDF format.

- Asynchronous API built with FastAPI.
- PDF text and embedded-image extraction using PyMuPDF.
- Custom regular-expression pipeline for structured data extraction.
- Firestore persistence and Docker-based deployment.
- Security-conscious handling of service credentials.

**Tech:** `Python` `FastAPI` `Firestore` `PyMuPDF` `Docker` `Render`

### ⚡ [APM Coding Challenge](https://github.com/lautarofamaf/Coding-Challenge-APM)

Algorithm-focused coding challenge centered on efficient range queries and updates.

- Dynamic segment tree for range-sum and point-update operations.
- Strict logarithmic-time operations, `O(log U)`.
- Lazy node instantiation to reduce memory usage.
- Defensive validation and separation between the algorithmic core and I/O.
- Randomized oracle tests, stress testing, and boundary-case coverage.

**Tech:** `Python` `Data Structures` `Algorithms` `Unit Testing`
