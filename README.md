## Featured projects

### 🎮 [Death on the Cards — Backend](https://github.com/lautarofamaf/dotc-backend)

Backend for a real-time multiplayer adaptation of *Death on the Cards*, developed as part of a Software Engineering project.

- Layered architecture with separated API, domain, game, persistence, and dependency-injection components.
- Real-time communication through **WebSockets**.
- Asynchronous workflows for concurrent clients and game sessions.
- Game-state management, domain rules, specialized services, and effect execution.
- REST endpoints, SQLAlchemy persistence, automated tests, and a maintainable modular structure.

**Tech:** `Python` `FastAPI` `WebSockets` `SQLAlchemy` `Pytest` `uv`

### 🐾 [DiagnoVET API](https://github.com/lautarofamaf/diagnovet-challenge)

Backend engineering challenge for processing veterinary reports in PDF format.

- Asynchronous FastAPI service for PDF ingestion.
- Text extraction and embedded medical-image processing with PyMuPDF.
- Regex-based pipeline for identifying patients, owners, dates, diagnoses, and study data.
- Firestore persistence, Docker packaging, and Render deployment.
- Secure handling of service-account credentials.

**Tech:** `Python` `FastAPI` `Firestore` `PyMuPDF` `Docker` `Render`

### ⚡ [APM Coding Challenge](https://github.com/lautarofamaf/Coding-Challenge-APM)

Algorithm-focused challenge for efficient interval averages and point updates.

- Dynamic segment tree supporting range queries and updates in `O(log U)`.
- Lazy node creation to keep memory usage proportional to accessed positions.
- Defensive validation and separation between the algorithmic core and I/O.
- Randomized oracle tests, stress testing with large workloads, and boundary-case coverage.

**Tech:** `Python` `Data Structures` `Algorithms` `Unit Testing`

## Academic and collaborative work

### 🖥️ Computer Architecture

Projects focused on processor organization, datapaths, pipelining, instruction execution, simulation, and hardware/software interaction.

- [Architecture Lab 1 — Pipelined LEGv8 Processor](https://github.com/lautarofamaf/lab1-adc2025-g40) — `SystemVerilog` `LEGv8` `CPU Design`
  - Implemented and extended a five-stage pipelined LEGv8 processor.
  - Added support for `LSL` and `LSR` instructions across the control unit, datapath, pipeline registers, and ALU.
  - Worked with forwarding logic, hazard detection, stalls, instruction memory, GPIO, switches, and LED animation.

- [Architecture Lab 2 — gem5 Processor Simulation](https://github.com/lautarofamaf/adc2025-lab2-adc2025-g40) — `Python` `gem5` `Computer Architecture`
  - Configured and ran processor simulations using different in-order and out-of-order CPU models.
  - Compared processor configurations and benchmarks through automated simulation scripts.
  - Collected and processed execution statistics to analyze architectural behavior.

- [Assembly Lab](https://github.com/lautarofamaf/odc-lab-asm) — `Assembly`
  - Low-level programming exercises focused on instruction execution, registers, memory, and processor behavior.

### 🧩 Programming Paradigms

Projects covering functional programming, object-oriented design, inheritance, polymorphism, encapsulation, parsing, heuristics, distributed data processing, and Apache Spark.

- [Paradigms Lab 1 — Functional Programming](https://github.com/lautarofamaf/paradigmas25-g28-lab1) — `Haskell`
  - Implemented composable functions for drawing and interpreting Escher-style figures.
  - Worked with recursion, higher-order functions, functional composition, the Gloss library, and graphical animation.

- [Paradigms Lab 2 — Object-Oriented Feed Reader](https://github.com/lautarofamaf/paradigmas25-g28-lab2) — `Java`
  - Built a console feed reader configured through JSON subscriptions.
  - Retrieved news feeds, parsed articles, and applied heuristics to identify frequently mentioned named entities.
  - Practiced inheritance, polymorphism, encapsulation, modular design, HTTP requests, and testable components.

- [Paradigms Lab 3 — Distributed Processing with Apache Spark](https://github.com/lautarofamaf/paradigmas25-g28-lab3) — `Java` `Apache Spark`
  - Distributed RSS and Reddit feed processing using Spark RDDs.
  - Extracted and aggregated named entities, categories, and topics through parallel transformations and `reduceByKey`.
  - Explored serialization, lazy transformations, fault tolerance, inversion of control, loose coupling, and scalable data processing.

### 🌐 Computer Networks

Projects focused on network communication, protocols, client/server interaction, and systems-level communication.

- [Networks Lab 0](https://github.com/lautarofamaf/lab0_Redes) — `HTML` `Networking Fundamentals`

- [Networks Lab 3](https://github.com/lautarofamaf/lab3-Redes) — `C++`

### ⚙️ Operating Systems

Projects focused on concurrency, synchronization, processes, kernel interfaces, and low-level systems programming.

- [Operating Systems Lab 2 — Semaphores in xv6](https://github.com/lautarofamaf/lab2-SO) — `C` `xv6`
  - Implemented semaphore primitives including channel allocation, initialization, close, `up`, and `down` operations.
  - Integrated the functionality into xv6 and developed a `pingpong` program to demonstrate process synchronization.
  - Worked with system calls, shared resources, blocking, wake-up behavior, and concurrent process coordination.

- [Operating Systems Lab 3](https://github.com/lautarofamaf/lab3-SO) — `C` `Operating Systems`
  - Systems programming project focused on operating-system mechanisms, process behavior, and low-level resource management.
